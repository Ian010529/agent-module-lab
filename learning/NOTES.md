# Teaching Notes

## Stable rules

- 使用 teach 式学习流程，不把聊天中的长篇讲解当作完成学习。
- 项目驱动、just-in-time：只学习当前 Slice 必需内容。
- 不提前生成未来 lesson。
- lesson 中优先要求先预测、判断、设计或作答，再查看解释。
- reference 源码用于验证和迁移，不机械复制。
- learning record 只记录已经通过回答、练习或实现证明的能力，不因为“看过”就标记掌握。
- 项目技术状态最终仍以 `docs/technical-map.md` 为准。
