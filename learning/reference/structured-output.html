Structured Output — Reference

用于复习和查阅，不替代 lesson。

一句话定义

Structured Output：把 LLM 的自然语言理解结果限制为程序可稳定消费的数据结构。

Schema：定义允许的字段、类型和值，是模型输出与下游程序之间的数据契约。

三种正确性不要混

层问题例子
Schema / type validity结构是否合法？amount 是否是 float，classification 是否属于 Literal
Semantic correctness模型有没有读对原文？原文 £1200，却提取成 £1500
Business validation结构化事实是否满足业务规则？报价 1800 是否超过预算 1500

Schema 设计原则

  • unknown 不要 guess：缺失字段允许 None 或明确 missing 状态。
  • ambiguous 不要制造 false precision：range、approximate、relative date 保留不确定性。
  • 有绑定关系的字段使用 nested object，例如报价金额与报价条件。
  • Literal 用于稳定的有限状态空间，不要把开放自然语言强塞成 enum。
  • 只建模下游决策真正需要的信息，不追求万能 schema。
