Lesson 0001 · Creator Reply Extraction

A schema is a contract,
not a truth detector.

这一课只解决一个问题：当 Creator Reply 被 LLM 变成结构化数据时，哪里是结构问题，哪里是理解问题，哪里应该交给确定性代码。

约 10–15 分钟 一个 tangible win 需要：你已经看过 RouterSchema
Why this matters

你的下游代码会相信这个对象。

Creator Outreach 的第一段不是“让模型写得像 JSON”，而是把自然语言回复变成后续程序能够消费的对象。LangChain 的 with_structured_output 就是为这种“按 schema 返回对象”的调用方式提供包装。[1]

Creator reply
      ↓
LLM interprets meaning
      ↓
structured object
      ↓
deterministic checks
      ↓
next workflow decision

Structured Outputs 可以约束输出去遵循给定 schema；但官方文档也明确提醒：结构正确不代表内容一定正确。模型仍然可能在语义上犯错。[2]

这一课结束时，你要能做到：
看到一个失败案例，立刻把它放到「结构验证 / 语义验证 / 规则验证」中的正确一层。
The model

同一封邮件，要过三道不同的门。

假设达人回复：

I'd love to collaborate.
My usual rate is 1800.
Paid usage may cost more.
1 · 语义层

LLM 要理解：愿意合作、1800 是 usual rate、paid usage 可能加价、货币未给出。

2 · 结构层

Schema 要检查：字段存在吗？类型对吗？枚举值合法吗？

3 · 规则层

代码再判断：若 budget=1500，1800 是否超预算？

这三层不能互相替代。Pydantic 可以做字段和 model-level validation；它验证的是数据是否满足你定义的类型和约束，而不是替你证明 LLM 对原邮件的理解是真的。[3]

Reference code

现在把这三层映射回 pinned 源码。

在我们固定的 agents-from-scratch commit 里，RouterSchema 把分类空间限制为三个合法值：

classification: Literal["ignore", "respond", "notify"]

随后模型被包装成 structured-output 调用：

llm_router = llm.with_structured_output(RouterSchema)

模型返回后，程序读取 result.classification，再用普通 if / elif 决定下一条路径。换句话说：“邮件是什么意思”由模型判断；“respond 之后去哪”由代码决定。[4]

最关键的一点：假如模型给了合法的 notify，schema 可以完全通过；但如果标准答案本该是 respond，任务仍然是错的。参考项目的 triage eval 正是通过和 reference output 做 exact match 来检查这种错误。[5]

Practice

不要复述定义。把错误放到正确的一层。

Case 1. Schema 允许 ignore/respond/notify。模型输出 notify，但这封邮件其实明确要求回复。哪一层出了问题？

Case 2. Schema 要求 amount: float，模型返回 amount="banana"。哪一层应该挡住它？

Case 3. 已提取 amount=1800，campaign budget 是 1500。判断是否超预算属于哪一层？

Retrieval gate

最后三题：不回看上面。

这不是“看懂了没有”，而是检查你能否从记忆里取出来。

1. 原文只有 “My rate is 1800.”，模型输出 currency="USD"，而 schema 允许 USD。错误属于？

2. `classification` 只允许 ignore/respond/notify，模型返回 reply。错误属于？

3. 已有 `quote=2500` 和 `max_budget=2000`。是否需要人工审批的第一步数值判断属于？

Takeaway

只记这一张图。

LLM: “这句话是什么意思？”
          ↓
Schema: “这个对象合法吗？”
          ↓
Code: “已知事实满足规则吗？”
